# 📂 guideline/sample_images — Ảnh minh họa cho Guideline

Thư mục này chứa ảnh chụp màn hình (screenshots) từ CVAT dùng để minh họa cho các Case trong `../LABELING_GUIDELINE_V1.md`.

## Danh sách ảnh cần có

| Tên file | Mô tả |
|---|---|
| `case1_occlusion_correct.jpg` | Biển báo bị che — cách vẽ box ĐÚNG (bao trọn cả phần bị che) |
| `case1_occlusion_wrong.jpg` | Biển báo bị che — cách vẽ box SAI (chỉ vẽ phần nhìn thấy) |
| `case2_cluster_correct.jpg` | Cụm biển báo — cách vẽ box ĐÚNG (2 box riêng biệt) |
| `case2_cluster_wrong.jpg` | Cụm biển báo — cách vẽ box SAI (1 box ôm trọn) |
| `mapping_trap_stop.jpg` | Biển STOP — minh họa nhãn đúng là `other` không phải `prohibitory` |

## Hướng dẫn thêm ảnh

1. Chụp màn hình CVAT sau khi vẽ annotation.
2. Đặt tên file theo quy ước ở bảng trên.
3. Copy file vào thư mục này.
4. Chèn vào Guideline tại vị trí `[Chèn ảnh Sample X vào đây]`.
